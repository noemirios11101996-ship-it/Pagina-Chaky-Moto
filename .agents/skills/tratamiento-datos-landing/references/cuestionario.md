# Cuestionario

Fuente: skill `politica-tratamiento-datos-co`, adaptada a la landing.

Haz las preguntas **por rondas**, máximo cinco por turno. Antes de cada ronda, llena todo lo que puedas desde el proyecto, `Docs`, el contexto de la empresa o un RUT o documento que el empresario comparta; la columna «Dónde buscarlo primero» indica dónde. Muestra lo que ya encontraste para que lo confirme y pregunta solo lo que falte. Si responde «no sé» o «después», sigue con `[COMPLETAR]`.

Si tienes una herramienta de preguntas de opción múltiple, úsala para las preguntas cerradas.
